# @groundswell/core

Client-side synchronization runtime and contracts.

## What This Package Provides

- Service contracts:
  - `Applicator<TEvent>`
  - `Storage<TEvent>`
  - `Transport<TEvent>`
  - `SyncEngine<TEvent>`
- Live runtime layer:
  - `syncEngineLive(...)`
- Error types:
  - `StorageError`
  - `TransportError`
  - `ValidationError`
  - `ApplicatorError`
  - `DuplicateEventError`
- Applicator composition helpers:
  - `applicatorFactory`
  - `applicatorTreeFactory`
  - `serverApplicatorFactory`
  - `serverApplicatorTreeFactory`

## Core Concepts

- Local event status tracks two independent phases:
  - `local`: local verify/apply
  - `remote`: remote publish
- The engine processes events through a queue.
- Pending events are replayed from storage at startup.
- Remote stream events are persisted, deduplicated, and locally applied.

## Main Runtime API

```ts
syncEngineLive(
  syncEngineTag,
  applicatorTag,
  storageTag,
  transportTag,
  options?
)
```

- `options.offset` is passed to `transport.listen({ offset })`.
- Returned layer provides a `SyncEngine` implementation.

`SyncEngine.ingest(...)` expects an event without `id` and `timestamp`; those are generated by the engine.

## Event Processing Behavior

For each local ingest:
1. Save event as `{ local: pending, remote: pending }`
2. Run applicator `verify` then `apply`
3. Update `local` status
4. Queue for remote publish
5. Publish using transport with retry policy
6. Update `remote` status

For each remote event:
1. Save as `{ local: pending, remote: success }`
2. Ignore duplicates
3. Queue for local processing
4. Verify/apply and update local status

## Retry and Error Semantics

- `TransportError` with `isRetryable: true` is retried (exponential backoff + jitter).
- Non-retryable transport failures set `remote: error`.
- `DuplicateEventError` from transport publish is treated as `remote: success`.
- Validation/applicator failures affect local status.

## Minimal Integration Pattern

```ts
import { syncEngineLive } from "@groundswell/core";

const SyncEngineLive = syncEngineLive(
  DomainSyncEngine,
  DomainApplicator,
  DomainStorage,
  DomainTransport,
  { offset: 0 }
);
```

You must provide live layers for:
- Applicator
- Storage
- Transport
